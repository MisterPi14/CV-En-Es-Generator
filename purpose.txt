# CV TRANSLATOR - PURPOSE & CONTEXT

## OBJETIVO PRINCIPAL
Herramienta para traducir currículums vitae a diferentes idiomas usando modelos de lenguaje locales (Ollama), manteniendo el formato profesional mediante plantillas.

## FLUJO ACTUAL DE LA APLICACIÓN

### 1. IMPORTACIÓN (cv_importer.py)
- Formulario interactivo para capturar datos del CV
- Usuario ingresa información paso a paso
- Guarda automáticamente en `resumes_loaded/` como JSON estructurado
- **ESTRUCTURACIÓN POR CÓDIGO**: No usa IA, el formulario genera JSON directamente

### 2. EXTRACCIÓN LEGACY (pdf_extractor.py)
- Lee archivos PDF usando pdfplumber
- Extrae texto plano sin estructura
- Solo usado en comando `extract` (no recomendado)

### 3. ESTRUCTURACIÓN LEGACY (ollama_client.py - structure_cv_with_llm)
**ESTADO**: Solo usado en comando `extract` (legacy)
**PROBLEMA**: Usa IA para estructurar (no determinístico)
**RAZÓN**: Los PDFs no tienen estructura semántica consistente

Estructura JSON objetivo:
```json
{
  "personal_info": {
    "name": "string",
    "email": "string",
    "phone": "string",
    "location": "string",
    "linkedin": "string"
  },
  "summary": "string",
  "experience": [
    {
      "title": "string",
      "company": "string",
      "duration": "string",
      "description": "string"
    }
  ],
  "education": [
    {
      "degree": "string",
      "institution": "string",
      "year": "string"
    }
  ],
  "skills": ["string"],
  "languages": ["string"],
  "certifications": ["string"]
}
```

### 4. TRADUCCIÓN (ollama_client.py)
**NUEVA IMPLEMENTACIÓN PROGRAMÁTICA**:

#### translate_text(text, target_lang, model)
- Función simple que traduce un texto
- Prompt minimalista: solo traduce, sin instrucciones de estructura
- Retorna texto traducido

#### translate_cv(cv_data, target_lang, model, progress, task)
- **CONTROL PROGRAMÁTICO**: El código mantiene la estructura JSON
- **IA SOLO TRADUCE**: Llama a translate_text() para cada sección
- **SELECTIVO**: Solo traduce lo que debe traducirse
  - ✅ Traduce: summary, job titles, job descriptions, degrees, skills, languages
  - ❌ NO traduce: personal_info, company names, institutions, dates, certifications
- **PROGRESO**: Actualiza barra de progreso después de cada traducción
- **ENSAMBLAJE**: Construye el JSON traducido programáticamente
- Retorna JSON con contenido traducido y estructura intacta

### 5. GENERACIÓN DE PDF (pdf_generator.py)
Soporta dos tipos de plantillas:

#### A. Plantillas HTML (templates/html/)
- modern.html: Diseño moderno con colores y etiquetas
- classic.html: Diseño clásico estilo académico
- Usa Jinja2 para renderizar datos en HTML
- Convierte HTML a PDF con WeasyPrint

#### B. Plantillas Word (templates/word/)
- Usuario crea archivo .docx con marcadores {{variable}}
- Marcadores disponibles: {{personal_name}}, {{summary}}, {{exp1_title}}, etc.
- python-docx reemplaza marcadores con datos reales
- docx2pdf convierte Word a PDF final

## COMANDOS DISPONIBLES

### python main.py import-cv [--output nombre.json]
**FUNCIONALIDAD IMPLEMENTADA**
Formulario interactivo para capturar datos del CV:
- Despliega preguntas paso a paso para cada sección
- Información personal, resumen, experiencia, educación, habilidades, idiomas, certificaciones
- Guarda automáticamente en JSON estructurado en directorio `resumes_loaded/`
- Permite múltiples entradas para experiencia y educación
- Genera nombre de archivo automático basado en el nombre
- Opción --output para especificar nombre de archivo personalizado

**SALIDA**: archivo JSON en `resumes_loaded/` con CV estructurado listo para traducir

**VENTAJA**: Estructuración 100% determinística, sin dependencia de IA

### python main.py models
Lista modelos LLM disponibles en Ollama local

### python main.py extract mi_cv.pdf
**ESTADO ACTUAL**: Extrae y estructura CV (usa IA para estructurar)
**PROBLEMA**: No traduce, solo estructura
**SALIDA**: archivo JSON con CV estructurado

### python main.py translate
**FUNCIONALIDAD ACTUAL**:
- Muestra lista interactiva de idiomas disponibles (English, Spanish, French)
- Usuario selecciona idioma destino por número
- Muestra lista interactiva de CVs disponibles en `resumes_loaded/`
- Usuario selecciona CV por número
- Muestra lista de modelos Ollama disponibles
- Usuario selecciona modelo por número
- Carga JSON directamente (sin usar IA para estructurar)
- **TRADUCCIÓN PROGRAMÁTICA**: El código mantiene la estructura JSON
- **IA SOLO TRADUCE TEXTO**: Traduce sección por sección
- Muestra barra de progreso con porcentaje y tiempo restante
- Guarda resultado en JSON o PDF según formato especificado

**LÓGICA DE TRADUCCIÓN**:
- ✅ Traduce: summary, job titles, descriptions, degrees, skills, languages
- ❌ NO traduce: nombres propios, empresas, instituciones, fechas, emails, teléfonos, certificaciones
- Cada sección se traduce individualmente
- El código ensambla el JSON final con las traducciones

**FUNCIONALIDAD PDF DESHABILITADA**:
- La opción de traducir desde PDF está comentada temporalmente
- Razón: Requiere IA para estructurar (no determinístico)
- Flujo recomendado: import-cv → editar JSON → translate
- Código mantenido para futura implementación con parser determinístico

Opciones:
- --format: json o pdf (default: json)
- --model: Modelo Ollama específico (opcional, se pregunta interactivamente)
- --template: html o word (solo si format=pdf)
- --template-name: Nombre de plantilla específica

Ejemplos:
```bash
# Traducir CV (todo interactivo: idioma, CV, modelo)
python main.py translate

# Traducir y generar PDF
python main.py translate --format pdf

# Traducir con modelo específico
python main.py translate --model llama3.2
```

### python main.py templates
Lista plantillas HTML y Word disponibles

## DEPENDENCIAS

### Core
- pdfplumber: Extracción de texto de PDFs
- ollama: Cliente Python para modelos LLM locales
- typer: CLI moderna
- rich: Output colorido en terminal
- pydantic: Validación de datos

### PDF Template Generation
- weasyprint: HTML a PDF
- jinja2: Motor de plantillas HTML

### Word Template Generation
- python-docx: Manipulación de archivos Word
- docx2pdf: Conversión Word a PDF (requiere MS Word instalado)

## PROBLEMAS RESUELTOS

### 1. ✅ ESTRUCTURACIÓN POR CÓDIGO IMPLEMENTADA
**Solución implementada**: Usuario proporciona JSON directamente mediante formulario interactivo
- Comando `import-cv` captura datos estructurados
- Guarda en `resumes_loaded/` como JSON
- Comando `translate` muestra lista de CVs disponibles para seleccionar
- IA solo se usa para traducir texto, no para estructurar

### 2. ✅ TRADUCCIÓN PROGRAMÁTICA IMPLEMENTADA
**Solución implementada**: El código controla la estructura, IA solo traduce texto
- Función `translate_text()`: Traduce texto simple sin responsabilidad de estructura
- Función `translate_cv()`: Itera sección por sección, traduce selectivamente
- El código ensambla el JSON final con las traducciones
- Más confiable, rápido y predecible que delegar estructura a IA

### 3. ✅ SELECCIÓN INTERACTIVA COMPLETA
**Solución implementada**: Todo el flujo es interactivo con listas numeradas
- Selección de idioma (English, Spanish, French)
- Selección de CV desde `resumes_loaded/`
- Selección de modelo Ollama
- Selección de plantilla (si genera PDF)
- Barra de progreso con porcentaje y tiempo restante

## PROBLEMAS PENDIENTES

### 1. COMANDO EXTRACT (LEGACY)
**Estado**: Funcional pero no recomendado
**Problema**: Usa IA para estructurar desde PDF (no determinístico)
**Recomendación**: Usar `import-cv` en su lugar
**Acción**: Considerar deprecar o documentar como legacy

### 2. FUNCIONALIDAD PDF EN TRANSLATE DESHABILITADA
**Estado**: Código comentado temporalmente en main.py
**Razón**: Requiere IA para estructurar (no determinístico)
**Flujo actual**: import-cv → translate (solo JSON)
**Pendiente**: Implementar parser determinístico para PDFs o mantener flujo actual

### 3. VALIDACIÓN CON PYDANTIC
**Estado**: Modelos definidos en cv_structure.py pero no usados
**Pendiente**: Implementar validación antes de traducir
**Beneficio**: Detectar errores en estructura JSON antes de procesar

## MODELOS OLLAMA RECOMENDADOS
- llama3.2 (3B): Rápido, bueno para traducción de textos cortos
- mistral (7B): Balance velocidad/calidad
- gemma2/gemma3 (9B): Excelente para múltiples idiomas
- qwen2.5 (7B): Muy bueno para traducción precisa

**NOTA**: Ya no se requieren modelos buenos en "estructuración" porque la estructuración es programática

## INSTALACIÓN Y ENTORNO VIRTUAL

### install.py
- Crea entorno virtual en `~/.python-envs/cvTranslator`
- Instala todas las dependencias desde requirements.txt
- Uso: `python install.py`

### uninstall.py
- Elimina el entorno virtual y todas sus dependencias
- Solicita confirmación antes de eliminar
- Uso: `python uninstall.py`

### main.py - Activación Automática de Venv
- Verifica si el venv existe en `~/.python-envs/cvTranslator`
- Si no está activo, re-ejecuta el script con el python del venv
- Si no existe el venv, muestra error y pide ejecutar install.py
- **IMPORTANTE**: El usuario no necesita activar manualmente el venv
